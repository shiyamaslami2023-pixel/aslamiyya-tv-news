ASLAMIYYA TV NEWS DASHBOARD

1. Keep index.html and news.js in the same folder.
2. Open index.html in Chrome or Edge.
3. Press F11 (or browser full-screen) and connect laptop to the 42-inch TV via HDMI.
4. Headlines rotate automatically every 9 seconds and the bottom ticker scrolls continuously.
5. Daily content is stored only in news.js. The visual design stays unchanged.

This first version is a local working prototype. Automatic online daily updating requires a hosted data source or online dashboard endpoint.
